## 四、問題回答

**問題一：為什麼 "4" 要先轉成數字，才能用於本題的分攤計算？**

因為 "4" 是字串，不是數字，無法直接用來進行除法計算，所以需要使用 int() 將它轉成整數 4，才能算出每人分攤的費用。

**問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？**

先扣除折價券：1200 − 100 = 1100 元。

計算服務費：1100 × 0.10 = 110 元。

應付總額：1100 + 110 = 1210 元。

因為先扣除折價券會讓計算服務費的金額變少，所以最後的應付總額會比題目規定的 1220 元少 10 元。
